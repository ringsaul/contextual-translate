# Contextual Translate

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

**いつもどおり Agent に質問しながら、同じことを外国語で自然に伝える表現も学べます。**

## このスキルでできること

- **普段の会話で語学に触れる**：コードについて質問したり、不具合を調べたりしながら、同じ依頼を外国語でどう伝えるか確認できます。翻訳のあとも、Agent は元の依頼に対応します。
- **Q と N を見比べる**：Q は伝えたい内容を学習する言語で表し、N は同じ場面での自然な言い方を示します。単語の選び方や文の組み立てを比較できます。
- **会話の流れを踏まえて訳す**：前のやり取りを参照して「これ」「それ」が何を指すかを理解し、用語もそろえます。
- **スペルや文法を直す**：学習中の言語で直接質問できます。明らかな誤りがあれば修正した文を示し、ポイントを一、二点説明します。
- **翻訳と回答の言語を別々に設定する**：英語やフランス語の表現を学びながら、解説や回答は日本語で読めます。
- **学習メモは短く**：覚えておきたい表現を太字にし、必要なときだけ短い解説を添えます。Q/N と本来の回答は分けて表示します。

## 1. Agent にインストールを頼む

次のメッセージを Agent に送ってください。

```text
このスキルをインストールしてください。私の質問は英語に翻訳し、学習メモと回答本文は日本語にしてください：https://github.com/ringsaul/contextual-translate
```

「英語」を学びたい言語に置き換えるだけです。インストール後は普段どおりに質問できます。会話の途中で翻訳先の言語を変更することもできます。

Agent は[インストール手順](docs/installation.md)と `examples/` を参照し、このスキルに対応する有効なルールに、指定した言語と毎ターン使用する設定を追加します。他の設定は保持し、適用範囲や再読み込みの必要性も説明する想定です。

手動インストール、更新、一時停止、アンインストールについては[インストール手順](docs/installation.md)をご覧ください。詳細ガイドとスキルの指示は現在、簡体字中国語で記載されています。上のインストール依頼では、学習メモと回答本文を日本語にすることを明示しています。

## 2. 会話の例

### 文脈を踏まえて質問を翻訳する

翻訳先は英語、学習メモと回答は日本語に設定した例です。

**ユーザーの入力：**

```text
このスキルは、それまでの会話を踏まえて質問を翻訳できますか？
```

**Agent の返信例：**

> **Q:** Can this skill use context when translating my questions?
>
> **N:** Can it **take our conversation into account** when translating my questions?  
> *「take … into account」は「〜を考慮に入れる」という意味です。ここでは、それまでの会話を翻訳に反映することを表します。*

---

はい。現在のルールでは、会話の文脈を踏まえて質問を理解するように指定されています。前のやり取りから「このスキル」などの指示語や省略された内容を読み取り、用語もそろえます。

Q は元の意図を伝える表現、N はその場面に合う自然な表現です。会話を参照しても重要な点が不明な場合は、勝手に要件を補わずに確認します。

### 文法に誤りがある場合

翻訳先は引き続き英語です。ここでは、ユーザーが英語で直接質問しています。

**ユーザーの入力：**

```text
How often should I waters my plants?
```

**Agent の返信例：**

> **Q:** How often should I **water** my plants?
>
> **N:** How often do I **need to water** my plants?  
> *「waters → water」：should のあとには動詞の原形を使います。「need to water」は「水やりをする必要がある」という表現です。*

---

植物の種類と土の乾き具合によります。毎日決まった時間に水をやるのではなく、まず土の状態を確認しましょう。

何の植物を育てていますか？ 室内と屋外のどちらに置いていますか？ それが分かると、より具体的にお答えできます。

文法を一か所直したあと、そのまま元の質問に回答します。

## 3. Q と N の意味

| 部分 | 意味 | 表示する内容 |
| --- | --- | --- |
| **Q — Question** | 質問や依頼を翻訳先の言語で表したもの | 元の意図を伝える文。すでにその言語で入力している場合は、明らかなスペル・語法・文法の誤りを修正 |
| **N — Native phrasing** | その場面で自然に使われる表現 | 文脈に合う言い方。学習に役立つ表現だけを太字で表示 |
| N の下の斜体部分 | 短い学習メモ | 表現や修正のポイントを一、二点解説。説明する価値のある違いがなければ省略 |
| 区切り線のあとの本文 | Agent の本来の回答 | 翻訳だけで終わらず、質問への回答や依頼された作業を実行 |

Q は入力文をそのまま繰り返すものではなく、N も質問への回答ではありません。どちらもユーザーの意図を表し、本来の回答はそのあとに続きます。Q がすでに自然な場合、N が同じ文でも構いません。無理に言い換えることはしません。

## 4. 修正する範囲と例外

- 学習する言語の明らかなスペル・語法・文法の誤り：Q で修正し、重要な点を一、二点説明します。
- 正しい口語表現や地域による違い：誤りとして扱わず、N を変えるためだけの書き換えもしません。
- 誤りによって重要な意味が分からない場合：意味を確認してから回答し、その意味に依存する操作を行います。
- コード、変数名、コマンド、パス、エラーメッセージの原文、固有名詞：誤字のように見えても勝手に変更しません。
- 翻訳だけを依頼した場合：Q/N と必要な学習メモを示し、翻訳した質問への回答は追加しません。
- 「JSON のみ」「コードのみ」や翻訳を省略する指示がある場合：指定された形式を崩す Q/N は追加しません。

## 5. 翻訳先の言語を指定する

**翻訳先、学習メモ、回答本文の言語は、それぞれ指定できます。**

このページでは、日本語で質問しながら英語を学ぶ使い方を紹介しています。英語以外にも、学びたい言語に切り替えられます。

| Agent に伝える内容 | 適用範囲 |
| --- | --- |
| これからは質問を英語に翻訳して | この会話内で、変更するまで英語を使用 |
| 今回だけフランス語に翻訳して | このターンだけ適用し、次は前の設定に戻る |
| 翻訳先をスペイン語に変えて | この会話の以降のターンでスペイン語を使用 |
| ドイツ語に翻訳して、解説と回答は日本語のままにして | Q/N はドイツ語、学習メモと本文は日本語 |
| 翻訳先を韓国語に変えて | この会話の以降のターンで韓国語を使用 |
| 翻訳にはイギリス英語を使って | この会話内でイギリス英語の表現を使用 |
| 今回は翻訳を省略して | このターンは直接回答 |

言語名、明確な言語コード、地域別の表現で指定できます。たとえば、英語 / `en`、スペイン語 / `es`、フランス語 / `fr`、日本語 / `ja`、ドイツ語 / `de`、韓国語 / `ko`、ブラジルのポルトガル語などです。固定の対応言語一覧ではありません。実際の翻訳品質はモデルによって異なります。

**新しい会話でも毎回英語にしたい場合**は、次のように依頼してください。

```text
contextual-translate のグローバルな翻訳先を英語に設定してください。
学習メモと回答本文は日本語のままにしてください。
このスキルに対応する、実際に読み込まれる個人用の常設ルールに設定を保存し、
他の設定は保持してください。適用範囲も説明してください。
```

「今回だけ」「これからは」は、そのターンや現在の会話に適用され、他の会話の設定を自動では変更しません。会話をまたいで設定を維持するには、実際に有効な個人ルールの変更を明示的に依頼する必要があります。プロジェクト単位のルールしか使えないツールでは、そのプロジェクト内に適用されます。
