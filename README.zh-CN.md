# Contextual Translate

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

**正常与 Agent 对话，同时学习如何用另一种语言准确、自然地表达。**

## 项目优势

- **日常对话中练语言**：问代码、查问题时，顺便看看同一句话用外语怎么说。翻译之后，Agent 会继续回答你的问题。
- **Q/N 对照**：Q 用目标语言表达你的原意，N 给出母语者常用的说法，方便比较用词和句式。
- **结合上下文翻译**：参考前面聊过的内容，理解“这个”“它”指的是什么，也沿用对话中的术语。
- **拼写和语法纠正**：可以直接用正在学的语言提问。有明确错误时，显示改后的句子，并解释一两处关键错误。
- **分别设置翻译和回答语言**：想练日语就设成日语，想练法语就换成法语，解答仍然可以看中文。
- **简短的学习提示**：值得注意的词组会加粗，有必要时再补一句解释。Q/N 和正式回答分开展示，方便阅读。

## 1. 让 Agent 帮你安装

把下面这句话发给你的 Agent：

```text
帮我安装这个 skill，翻译语言为英语：https://github.com/ringsaul/contextual-translate
```

把“英语”换成你想学习的语言即可。安装完成后直接正常提问，后续也可以在对话中切换语言。

Agent 安装时应参考 [安装说明](docs/installation.md) 和 `examples/`，将指定语言与每轮使用要求写入本技能对应的有效规则区块，保留其他配置，并说明生效范围与是否需要重载。

手动安装、更新和卸载见[安装说明](docs/installation.md)。



## 2. 完整对话效果

### 结合上下文翻译提问

**用户输入：**

```text
这个skill可以结合上下文翻译我的提问吗
```

**Agent 回复示例：**

> **Q:** Can this skill use context when translating my questions?
>
> **N:** Can it **take our conversation into account** when translating my questions?  
> *“take … into account” 表示把前面的对话内容考虑进去。*

---

可以，现有规则已经要求结合上下文理解你的提问。我会根据前面的对话理解“这个 skill”等指代、补全省略信息，并保持术语一致。

Q 侧重准确表达原意，N 侧重结合语境的自然表达；如果上下文仍不足以确定意思，会先确认，不擅自补充需求。



### 提问有语法错误时

**用户输入：**

```text
How often should I waters my plants?
```

**Agent 回复示例：**

> **Q:** How often should I **water** my plants?
>
> **N:** How often do I **need to water** my plants?  
> *原句中的 waters 应改为 water，因为 should 后接动词原形；need to water 表示“需要浇水”。*

---

要看植物种类和盆土的干湿情况。先检查土壤，再决定是否浇水，不必固定每天浇。

你养的是什么植物？放在室内还是室外？知道这些后，可以给你更具体的建议。

这个例子只修正一处语法错误，然后照常回答问题。

## 3. Q 和 N 是什么意思

| 部分 | 含义 | 展示内容 |
| --- | --- | --- |
| **Q — Question** | 问题或请求的目标语言版本 | 用目标语言准确表达你的原意；已用目标语言提问时，修正明确的拼写、用词或语法错误 |
| **N — Native phrasing** | 母语者在这个场景下常用的表达 | 结合上下文给出自然说法，只加粗值得学习的关键词组 |
| N 下方斜体说明 | 简短学习提示 | 按需解释关键表达或错误，通常一到两点，没有有价值的差异时省略 |
| 分隔线后的正文 | Agent 的实际回答 | 正常回答问题或执行任务，不会只给翻译就结束 |

Q 不是把原句原样复述；N 也不是问题的答案。两者都保留你的意图，真正的回答在后面的正文中。原句已经自然时允许 Q/N 相同，不强行换词。



## 4. 纠错范围和例外

- 英语及其他目标语言中明确的拼写、用词或语法错误：在 Q 中修正，并优先解释一到两个关键错误。
- 已正确的口语或地区变体：不当作错误，不为了生成 N 硬改。
- 错误导致关键含义不明确：先确认意思，再回答或执行依赖该含义的操作。
- 代码、变量名、命令、路径、报错原文与专有名称：不擅自当作错词修改。
- 只要求翻译：只给翻译、自然表达和有价值的说明，不额外回答译文中的问题。
- 要求“只输出 JSON”“只输出代码”或显式跳过：不添加会破坏格式的 Q/N 内容。

## 5. 指定翻译语言

**翻译语言、说明语言和正式回答语言可以分别指定。**

本页以中文提问、学习英语为例。英文版展示英语提问、学习西班牙语；日文版展示日语提问、学习英语。你也可以换成其他想学的语言。

| 你对 Agent 说                    | 生效方式                           |
| -------------------------------- | ---------------------------------- |
| 接下来都把我的问题翻成西班牙语   | 当前会话持续用西班牙语，直到再次修改 |
| 这次把我的问题翻成日语           | 仅这一轮用日语，下一轮恢复先前设置 |
| 接下来都把我的问题翻成法语       | 当前会话持续用法语，直到再次修改   |
| 翻译成韩语，解释和正文仍然用中文 | Q/N 用韩语，说明与正文用中文       |
| 接下来使用英式英语               | 当前会话采用英式措辞               |
| 翻译成德语，解释和正文仍然用中文 | Q/N 用德语，说明与正文用中文       |
| 恢复英语翻译                     | 将当前会话目标语言切回英语         |
| 这次跳过翻译                     | 本轮直接回答                       |

支持用明确的语言名称、代码或地区变体指定目标语言，例如英语 / `en`、西班牙语 / `es`、法语 / `fr`、日语 / `ja`、德语 / `de`、韩语 / `ko`，也可以指定英式英语、巴西葡萄牙语等。这些是示例，不是固定支持列表，实际语言质量取决于模型。

**希望所有新会话默认使用法语？** 把下面这句话发给 Agent：

```text
请把 contextual-translate 的全局默认翻译语言设为法语，
说明和正式回答仍用简体中文。
将偏好写入本技能对应的个人常驻规则区块，保留其他配置，并说明生效范围。
```

“这次”和“接下来”只改变本轮或当前会话，不会自动修改其他会话。要跨会话保持，需像上面这样明确要求修改实际生效的个人规则；如果工具仅支持项目规则，配置范围就是该项目。
